# pySPEDAS

Python port of the IDL-based SPEDAS (Space Physics Environment Data Analysis System) library. Provides a unified interface for querying, loading, and time-aligning heliophysics datasets — including [[OMNI]] solar wind, ground magnetometers, and most NASA heliophysics mission data products.

Citation: Grimes et al. (2022), *Frontiers in Astronomy and Space Sciences*.

## Use in research

In [[Lundquist Varney 2026]], pySPEDAS is the tool used to query OMNI and interpolate solar-wind / IMF / geomagnetic-index values onto the [[RISR-N]] 1-min observation timestamps for the L/D/LD event analysis.
